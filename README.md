# Neural Chain

Neural Chain is a high-stakes cognitive memory game where players compete to build and recall an ever-growing sequence of items within specific domains like geography, technology, or cinema. Designed with a sleek, minimalist cyberpunk aesthetic, the app challenges your brain to accurately replay the entire sequence before appending a new unique node, creating a tense battle of mental endurance against sophisticated AI units. With real-time text-to-speech feedback and a dynamic neural-link interface, it transforms simple list-making into an immersive, competitive experience that pushes your mnemonic limits.

## Features

- **Neural Memory Loop**: Every turn requires you to recall the *entire* existing chain in exact order before you can add your own contribution.
- **AI Competitors**: Test your recall against multiple AI units with varying levels of endurance.
- **Smart Completion**: If you've typed a significant portion of a valid item, the system offers neural sync suggestions to speed up your throughput.
- **Text-to-Speech**: Immersive voice synthesis announces each link in the chain, making the mental challenge feel like a real-time data sync.
- **Multiple Domains**: Switch between Countries, Tech Brands, Famous Movies, and historical Icons.

## How to Play

1. **Initialize Phase**: Set your domain (e.g., Countries) and the number of AI opponents.
2. **Recall Cycle**: On your turn, you must type each item in the existing chain one-by-one. Each correct entry "syncs" the node.
3. **Append Cycle**: Once the chain is recalled, add a new, unique item that hasn't been used yet.
4. **Elimination**: One mistake in the sequence or repeating an item results in instant neural disconnection (elimination).
5. **Winning**: Be the last "brain" online to claim victory.

## Tech Stack

- **React 18** + **Vite**
- **Tailwind CSS** for the futuristic UI
- **Motion (Framer Motion)** for fluid route and state transitions
- **Web Speech API** for natural-sounding voice synthesis
- **Lucide React** for minimalist iconography
